## Thought 

Given the context that I keep thinking about and making objects related to the **female inner body system**, the next project I want to develop is an “eco-pond”. I have been creating some digital life forms, either using machine learning to analyse the DNA sequence of an illuminant bacteria, or generative systems to make an object move and grow with autonomy. So I am thinking about body systems and electronic systems. Body systems run to keep humans and animals alive, just as all the electronic components run together to make machines work.  

My last project was a vending machine indicating how the inner body is invisible, while fem-tech products are growing and taking women’s money in this capitalist society. One of the reasons I chose a vending machine was because people know how to interact with it without extra thought.  

This time I would like to compare and combine the similarities between an eco-pond and a pinball arcade machine. They both provide an **uncertain but clearly visible environment**, allowing the ball (life) to move and react to the features inside the box. In this project, I aim to create a large-scale installation and also use an API to control and visualise the data through the movement of the machine.
